# Mahakal Steel - Industrial Steel Supplier & Stockholder

Official website for **Mahakal Steel**, Mumbai's premier industrial steel stockist and distributor located in Sakinaka, Mumbai.

## 🚀 Live Features
- **Steel Catalog**: Hot & Cold Rolled Plates, Seamless Pipes & Tubes, Mild Steel Sections (Channels, Angles, Flats), Stainless Steel 304/316, and Heavy Structural Beams (ISMB, Columns).
- **Verified Facility**: GSTIN registered (`27DLSPR1147D1ZU`) with official stockyard at Gala No. 10, Bunavad Market, Sakinaka Link Road, Mumbai.
- **Material Compliance**: MTC 3.1, ISO 9001:2015, BIS & ASTM test compliance.
- **Instant Inquiry & Quotation**: Integrated WhatsApp order routing and quotation request generator.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Routing**: React Router v7
- **Bundler**: Vite
- **Icons**: Lucide React

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/its-sartaj/mahakal_-steel.git
   cd mahakal_-steel
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🌐 Deploying Live

### Vercel / Netlify (Recommended)
1. Push this repository to GitHub (`https://github.com/its-sartaj/mahakal_-steel`).
2. Go to [Vercel](https://vercel.com) or [Netlify](https://netlify.com) and import the repository.
3. Keep default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Deploy! All routes and assets are pre-configured with `vercel.json` and `_redirects`.
